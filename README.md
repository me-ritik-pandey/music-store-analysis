# Music Store SQL Analysis

## About the Project

This is a SQL data analysis project based on a fictional music store
database.

The main goal of the project is to use SQL to explore the data and
answer business-related questions about customers, sales, invoices,
artists, tracks, and music genres.

I worked through the project in three levels --- Easy, Moderate, and
Advanced --- starting with basic SQL queries and gradually using more
advanced SQL techniques.

## Database

The database contains several related tables, including:

-   Employee
-   Customer
-   Invoice
-   InvoiceLine
-   Track
-   Album
-   Artist
-   Genre
-   MediaType
-   Playlist
-   PlaylistTrack

The tables are connected through primary and foreign keys, which makes
it possible to analyze information across different parts of the
database.

## What I Analyzed

Some of the main questions explored in this project include:

### Easy Level

-   Finding the most senior employee
-   Finding countries with the most invoices
-   Identifying the top invoice totals
-   Finding the city with the highest total invoice amount
-   Finding the customer who spent the most money

### Moderate Level

-   Finding customers who purchased Rock music
-   Identifying the top Rock artists based on track count
-   Finding tracks that are longer than the average track length

### Advanced Level

-   Analyzing customer spending related to the best-selling artist
-   Finding the most popular music genre in each country
-   Identifying the top-spending customer in each country

## What I Learned

This project gave me practical experience in turning business questions
into SQL queries.

It helped me become more comfortable with relational databases,
especially when working with multiple tables and connecting data through
joins. I also got hands-on practice with aggregation, subqueries, CTEs,
and window functions for more complex analysis.

One of the main things I learned from this project is that writing SQL
is not just about getting an answer --- it is also about understanding
the database structure and choosing the right approach to answer a
business question clearly and accurately.
